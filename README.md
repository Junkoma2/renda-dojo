# renda-dojo

10秒間で何回タップできるか挑戦する連打ゲームです。

## なぜ作ったか

あるパーティーゲームの連打系ミニゲームで勝ちたくて、練習用に作りました。
10秒間のタップ回数と反応をシンプルに記録するだけの、連打力トレーニング専用アプリです。

## 遊び方

1. 「スタート」ボタンを押してゲームを開始
2. 制限時間10秒間、画面中央のボタンを連打
3. カウントが記録され、終了後に結果を確認できます
4. スペースキーでもタップできます
